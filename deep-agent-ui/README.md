# deep-agent-ui

React app (Vite, Tailwind, `@langchain/react` v1 `useStream`) that visualizes the project's coding Deep Agent in real time:
- transcript and tool-call cards;
- todos;
- subagent cards;
- structured result;
- sandbox file tree, code and diff;
- token usage and LLM cost.

Start the Agent Server from the repository root first, then `npm install && npm run dev`. See [../docs/DEEP-AGENT-STUDIO.md](../docs/DEEP-AGENT-STUDIO.md).
